# Escalas de Avaliação

Site com páginas para consulta e preenchimento de duas escalas: ATA e M-CHAT.

## Acessar o projeto

- **Site publicado:** https://escala-avaliacoes.netlify.app/
- **Escala ATA:** https://escala-avaliacoes.netlify.app/ata
- **M-CHAT:** https://escala-avaliacoes.netlify.app/mchat

## Tecnologias

- HTML
- CSS
- JavaScript

As páginas estão implementadas em arquivos HTML individuais, com estilos e scripts incluídos nos próprios arquivos. O ícone do site está em `icone.png`.

## Executar localmente

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Escolha a escala desejada na página inicial.

Também é possível iniciar um servidor local simples na pasta do projeto, por exemplo com Python:

```bash
python -m http.server 8000
```

Depois, acesse http://localhost:8000.

## Observação importante

Este projeto é uma ferramenta digital de preenchimento e cálculo. Não substitui avaliação profissional, diagnóstico ou orientação clínica. A interpretação dos resultados deve seguir as instruções oficiais de cada instrumento e ser feita por profissional habilitado.
